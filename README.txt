How to run:

1) Open VS Code 

2) Create a virtual Environment

3) Drop an OpenAPI key in .env file

4) Navigate to the folder where files have been downloaded from Git in VS Code

5) Navigate to app folder and then to  steamlit_app.py

6) Go to Terminal

	Type the following each and hit enter: 
	pip install -r 'requirements.txt'
	pip install streamlit
	pip install dotenv

	(if you see you do not have any installed libraries follow the above format and install them)

	To run the app type: streamlit run app.py
